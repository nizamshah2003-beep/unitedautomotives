# United Automotives India

Static HTML/CSS site deployed to Vercel. No build step, no dependencies.

## Deploy target

GitHub repository: https://github.com/nizamshah2003-beep/unitedautomotives

**Standing instruction from the user:** after any change to this project, commit and push the
updated code to this repository. Do this every time unless the user says otherwise.

## Before deploying

`REPLACE-WITH-YOUR-DOMAIN` appears in `index.html`, `robots.txt`, and `sitemap.xml`. It must be
replaced with the real production domain, or the canonical URL will be wrong.

Verify `git` is installed and credentials are available before attempting a push.
